# Apex

A local system for the school organization president to track members, attendance, points, and warnings.

The system runs on one laptop. Phone access is out of scope for now. Only the president has an account; members are records.

## Project folders

- `frontend` - React user interface
- `backend` - Spring Boot API and database migrations
- `branding/apex` - Apex logo source and exported assets

Development setup and backend run instructions are in [`backend/README.md`](backend/README.md).

Member management setup, rules and learning checklist: [`docs/stage-9.md`](docs/stage-9.md).
